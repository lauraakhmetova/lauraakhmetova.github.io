# Портфолио Лауры Ахметовой

Откройте `index.html` в браузере двойным нажатием. Установка и подключение к интернету для просмотра сайта не нужны. Сайт также можно открыть через любой локальный HTTP-сервер.

Кнопка с полукругом в шапке переключает графитовую и розовую темы. Выбранная тема запоминается в браузере. Ленту работ можно остановить кнопкой «Пауза ленты».

Внешние ссылки на Telegram, резюме и социальные профили сохранены с исходными адресами; для их открытия нужен интернет. Пять страниц проектов находятся в `project-details`, изображения, видео и шрифты — в `assets`. Тексты страниц находятся непосредственно в HTML.

## Сменные изображения проектов

В `index.html` атрибут `data-hover-image` указывает на изображение, которое появляется при наведении на кейс или переходе к ссылке с клавиатуры. Чтобы заменить изображение, положите новый файл в `assets/img/` и укажите путь к нему в атрибуте соответствующего кейса. У «Игры для двоих» обложка собрана средствами HTML и CSS по палитре и знаку кейса. Для включения дополнительного изображения укажите изображение этого кейса и удалите атрибут `data-hover-preview="off"`.
