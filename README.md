# Портфолио Лауры Ахметовой

Откройте `index.html` в браузере двойным нажатием. Установка и подключение к интернету для просмотра сайта не нужны. Сайт также можно открыть через любой локальный HTTP-сервер.

Кнопка с полукругом в шапке переключает графитовую и розовую темы. Ссылка «Выбрать анимацию бантиков» на первом экране ведёт к трём вариантам движения; выбранный вариант применяется к бантикам на первом экране. Настройки запоминаются в браузере. Ленту работ можно остановить кнопкой «Пауза ленты».

Внешние ссылки на Telegram, резюме и социальные профили сохранены с исходными адресами; для их открытия нужен интернет. Пять страниц проектов находятся в `project-details`, изображения, видео и шрифты — в `assets`. Тексты страниц находятся непосредственно в HTML.

## Сменные изображения проектов

В `index.html` у каждой ссылки с классом `project-card` есть атрибут `data-hover-image`. Он указывает на изображение, которое появляется после анимации при наведении. Чтобы заменить его, положите новый файл в `assets/img/` и укажите путь к нему в атрибуте соответствующей карточки.
